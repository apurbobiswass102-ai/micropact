## ⚡ The Problem
Every single day, millions of everyday transactions happen on verbal promises:
- Lending money to a friend or relative ("I'll pay you back next month")
- Freelancers doing work on verbal commitments without clear scope or milestone agreements
- Buying and selling secondhand smartphones, laptops, cameras, or bikes on Facebook Marketplace
- Roommates splitting rent and security deposits

**Why don't people make contracts?** Because hiring lawyers is slow and expensive, and enterprise tools like DocuSign or Adobe Sign are bloated, paid, and require complex accounts.

## 🚀 The Solution: MicroPact
**MicroPact** turns any agreement into a cryptographically verified, tamper-evident, 1-page legally binding PDF contract in under 60 seconds — for free, on any device.

### Key Capabilities:
1. **Ready-to-Use International Template Suite:**
   - 💸 **Personal Loan & Promissory Note (IOU)**: Amount, due dates, installment schedule, and default clauses.
   - 💻 **Freelance Milestone & Scope of Work**: Deliverables, revision limits, and copyright handover upon payment.
   - 🔒 **Instant Mutual NDA**: Protect secrets, pitch decks, and source code.
   - 🚗 **As-Is Bill of Sale**: Secondhand item purchase receipt with clear title transfer.
   - 🏠 **Roommate & Sublease Pact**: Rent portions, deposit holding, and notice period rules.
   - ⚡ **Universal Freeform Pact**: Tailor-made clauses for any mutual agreement.
2. **Statutory Legal Validity:**
   - Built under the U.S. **ESIGN Act** (15 U.S.C. § 7001) and EU **eIDAS Regulation** (EU No 910/2014).
3. **Tamper-Evident Cryptographic Seal:**
   - Instant SHA-256 hash calculated in real-time. Any post-signing tampering invalidates the hash.
4. **Magic Link Signing:**
   - Share via WhatsApp, Telegram, SMS, or Email. Counterparty opens it on their mobile phone and signs with their finger in 15 seconds.
5. **Live QR Code Notary Verification:**
   - Scan the QR code on the PDF to verify the original, unaltered document record.
6. **100% Client-Side & Private:**
   - Zero sensitive deal data stored on central databases. Your contracts stay between you and your counterparty.
   - **$0.00 Server Hosting Cost** on Vercel, Netlify, or Cloudflare Pages.

## 🛠️ Quick Start & Local Development

```bash
# Clone the repository
git clone https://github.com/your-username/micropact.git

# Navigate to directory
cd micropact

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```bash
npm run build
```

## 🌐 1-Click Free Deployment

You can host MicroPact completely free on:
- **Vercel**: Import your GitHub repo, select **Vite** framework preset, and hit Deploy.
- **Cloudflare Pages**: Connect repo, set build command to `npm run build` and output folder to `dist`.
- **GitHub Pages**: Deploy the `dist` folder directly via GitHub Actions.
